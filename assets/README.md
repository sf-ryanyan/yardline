## Product photos  (assets/products/)
One square photo per product, named after its SKU in lower case,
e.g. `fly-8511.jpg`. A product with no photo falls back to a line
drawing automatically, so photos can be added a few at a time.

All 26 product photos are in place.

Keep each file under about 150 KB. No text, logos or lettering inside images.
